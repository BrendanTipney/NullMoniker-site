# keyboard-media : what to drop in here

Drop files in with these exact names and the page picks them up with no code
changes. Anything you skip, leave the placeholder in keyboard.html and it will
still render cleanly.

Shoot everything on a plain background with one main light source. The site
desaturates images until hover, so form and contrast carry the shot, not colour.
Landscape, 4:3 or wider. 1600px on the long edge is plenty.

## Required

| File | What it is | Notes |
|---|---|---|
| `hero.jpg` | Both halves, three-quarter view | Also used on the home page work card |
| `01-mockup.jpg` | Paper or cardboard mockup | Skip and cut the step if you went straight to CAD |
| `02-cad.jpg` | Fusion 360 screenshot of the case | Shaded view, dark background if you can |
| `03-mount.jpg` | Trackpad mount revisions | The rejected prints lined up is the best shot on the page |
| `04-wiring.jpg` | Wiring, controller, guts | Case open, electronics visible |
| `05-keymap.jpg` | Keymap layers | A rendered layer diagram beats a photo here |

## Failures section

| File | What it is |
|---|---|
| `fail-01.jpg` | A print that warped, fit wrong, or came out unusable |
| `fail-02.jpg` | A mount version you rejected |
| `fail-03.jpg` | Rework: resoldered joint, a hole you had to drill out, a part you cut |

## Object gallery

| File | What it is |
|---|---|
| `object-hero.jpg` | Three-quarter, both halves, the money shot |
| `object-top.jpg` | Straight top down, showing the layout |
| `object-detail.jpg` | Close crop of the trackpad in the thumb path |
| `object-inuse.jpg` | Hands on the keyboard, for scale and posture |

## Optional

Short looping clips work anywhere an image does. Use `.mp4`, mute them, keep
them under about 8 seconds. A clip of the trackpad scrolling while the fingers
stay on the home row would sell the whole concept better than any still.

CAD files and STLs do not belong in this folder. Link them from a repo or a
release instead, and put the URL in the Specification table.
