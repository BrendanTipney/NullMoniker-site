# xr-media : drop-in footage

The XR page shows a placeholder for each of these until the file exists.
Drop a file in with the exact name and it appears on its own, no code changes.

Short muted loops work best: .mp4 (H.264), under about 10 seconds, 1280px wide or less.

| File | Where it shows |
|---|---|
| `asset15-menu.mp4` | Asset 15 : pulling a level down from the ceiling |
| `asset15-assembly.mp4` | Asset 15 : the volumetric assembly puzzle |
| `looking-glass-leap.mp4` | Touchable Hologram : Looking Glass + Leap Motion demo |

Already here (cut from clips/AR_DemoReel_NoTitle.webm):
asset15-logic, spatial-ui, volumetric-scene, ar-cards, ar-shopping, ar-web.

Other drop-ins around the site:
- `resume.pdf` in the site root turns on the Resume buttons on the home page.
- `keyboard-media/hero.jpg` replaces the keyboard placeholder on the Hardware page.
